# PDF 合并工具 设计文档

**日期**: 2026-06-22
**平台**: Windows 10/11
**语言**: Python 3.11+

## 概述

一个带 GUI 的 PDF 工具箱，支持合并、拆分、提取页面和旋转功能，打包为独立 .exe 运行。

## 技术选型

- **GUI**: tkinter（Python 自带）
- **PDF 引擎**: pymupdf (fitz) — 合并/拆分/旋转/渲染预览
- **预览增强**: Pillow — ImageTk 在 Canvas 上渲染
- **打包**: PyInstaller — 单文件 .exe

## 文件结构

```
pdf/
├── main.py          # 入口
├── gui.py           # 主界面
├── pdf_ops.py       # 核心 PDF 操作
├── preview.py       # 页面预览
├── requirements.txt
└── build.bat        # 打包脚本
```

## 模块职责

### main.py
- 创建 tkinter root 窗口
- 设置标题、图标、窗口大小
- 实例化主界面

### gui.py
- 标签页布局（合并/拆分/提取/旋转）
- 文件列表面板（显示文件名和页数）
- 添加文件/移除/排序按钮
- 执行操作按钮
- 进度条和状态提示
- 调用 pdf_ops 和 preview

### pdf_ops.py
- `merge_pdfs(file_paths, output_path)` — 合并多个 PDF
- `split_pdf(file_path, output_dir, pages_per_file)` — 拆分 PDF
- `extract_pages(file_path, output_path, page_ranges)` — 提取页码范围
- `rotate_pages(file_path, output_path, page_nums, angle)` — 旋转指定页面

### preview.py
- 基于 tkinter Canvas 的页面预览组件
- 使用 pymupdf 将 PDF 页面渲染为图片
- 支持翻页查看

## 各功能标签页

### 合并
- 添加多个 PDF → 调整顺序 → 点击"合并"
- 输出：选择保存位置 → 合并为一个 PDF

### 拆分
- 选择单个 PDF → 输入每 N 页拆一个文件
- 输出：选择输出目录 → 生成多个 PDF

### 提取
- 选择单个 PDF → 输入页码范围（如 1-3,5,7-9）
- 输出：选择保存位置 → 提取为一个 PDF

### 旋转
- 选择单个 PDF → 选择页码 → 选择角度（90°/180°/270°）
- 输出：选择保存位置 → 旋转后的 PDF

## 错误处理

- 文件不存在/已损坏 → 弹窗提示
- 页码范围格式错误 → 输入框变红提示
- 操作中断 → 状态栏显示错误信息
- 加密 PDF → 提示无法处理

## 打包

```bat
pyinstaller --onefile --windowed --name PDF工具箱 main.py
```

目标输出: `dist/PDF工具箱.exe`
